# trading-data-cleaning

Cleaning, feature engineering, and preparation of synthetic BTCUSDT order book data, following the EDA steps for trading data.

## Files
- eda1.py to eda9.py: one script per EDA step
- trades_orderbook_STUDENT_dirty.csv: raw input data

## Results
Output files and screenshots for each step are in the `results/` folder.
See `results/RESULTS.md` for a summary of each step.
